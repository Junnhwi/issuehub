# IssueHub 작업 일지

> 관심 분야(개발·AI·게임)의 이슈를 매시간 모아 한국어로 정리해 보여 주는 개인 큐레이션 사이트.
> 관심 있는 분야를 꾸준히 보고 깊이 공부하기 위해 만들었다.

- 사이트: https://issuehub-xi.vercel.app
- 저장소: https://github.com/Junnhwi/issuehub
- 기간: 2026-11-19 ~ 2026-11-22

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 화면 | Next.js 16 (App Router, Server Components), React 19, TypeScript, Tailwind v4 |
| 데이터 | Supabase (Postgres, RLS 읽기 전용, pg_cron, Vault) |
| 수집 | GitHub Actions + Node 스크립트 (Hacker News, RSS, GitHub, Steam, IsThereAnyDeal) |
| AI | Gemini 무료 티어로 영어 제목·본문 번역과 한국어 요약 |
| 배포 | Vercel (서울 리전 icn1), main에 푸시하면 자동 배포 |
| 테스트 | Vitest 59개, CI에서 lint·typecheck·test·build |

## 구조

1. Supabase pg_cron이 매시 20분에 GitHub Actions 수집 워크플로를 호출한다.
2. 수집기가 각 소스에서 글·저장소·게임을 받아 정규화하고 Supabase에 저장한다.
3. 요약기가 아직 요약되지 않은 항목을 Gemini로 번역·요약한다.
4. Vercel의 Next.js 서버가 Supabase를 읽어 화면과 읽기 전용 API로 보여 준다.

키(SUPABASE_SECRET_KEY, GEMINI/ANTHROPIC, GITHUB_TOKEN, ITAD_API_KEY)는 수집 스크립트와 서버에서만 쓰고 브라우저로는 보내지 않는다.

## 트러블슈팅

### 1. 예약 수집이 자주 빠짐

- 증상: "마지막 성공 수집"이 1~2시간 전으로 남아 있음.
- 원인: GitHub Actions `schedule`은 정시 보장이 없고 붐비는 시간(정각)에는 자주 건너뜀. 정각 예약은 14번 중 1번만 실행됨.
- 해결: Supabase pg_cron이 매시 20분에 `workflow_dispatch` API를 직접 호출. GitHub 예약(41분)은 예비로 둠.
- 추가 문제: pg_cron 호출이 401 Bad credentials → 토큰 재발급 후 Vault 값 교체 → 204 성공.
- 배운 점: 무료 스케줄러는 "언젠가 실행"에 가깝다. 정확한 시각이 필요하면 DB 쪽 cron처럼 믿을 수 있는 트리거를 쓴다.

### 2. Steam 출시일이 하루씩 어긋남

- 원인: 한국 시간으로 날짜를 표시했지만 Steam 상점은 미국 태평양 시간 기준.
- 해결: 출시일은 America/Los_Angeles 날짜로 표시.

### 3. Steam 목록이 빈약함

- 원인: `featuredcategories`의 출시 예정 목록이 내일 나오는 작은 게임 위주.
- 해결: 상점 검색의 인기 목록(topsellers, popularnew, popularcomingsoon)을 쓰고, 실패하면 기존 목록으로 대체. 리뷰 API는 리다이렉트돼서 GetItems의 리뷰 요약을 사용.

### 4. Vercel 배포 후 모든 데이터 요청이 500

- 증상: 약 7초 로딩 후 오류 화면, 로그에 `DB_ERROR:`(코드 없음).
- 과정:
  1. 환경 변수가 Secret 타입으로 저장돼 값 확인·수정 불가 → 삭제 후 Config로 다시 등록.
  2. Node 버전을 24로 고정하고, 오류 로그에 원인 메시지를 남기도록 수정.
  3. 로그에 "Invalid API key" → Supabase 공개 키 값이 잘못 붙여 넣어져 있었음 → 올바른 값으로 교체.
- 결과: 모든 페이지 200 응답, 0.2~0.5초.
- 배운 점: 오류 코드가 비어 있으면 메시지를 로그에 남겨야 원인을 찾을 수 있다(키 값은 남기지 않기).

## 설계 원칙 (지킨 것)

- 데모 데이터는 가상임을 분명히 표시하고, 실제 뉴스처럼 만들지 않는다.
- AI 요약은 완료된 것만 보여 준다. 가짜 요약 없음.
- Star 증가량은 서로 다른 날짜 스냅샷이 2개 이상일 때만 계산한다.
- 가격 기록은 IsThereAnyDeal 데이터를 그대로 보여 주고 출처를 표시한다(KR 데이터는 2024-12-07부터).
- 공개 쓰기 API 없음. 비밀 키는 클라이언트로 보내지 않는다.
